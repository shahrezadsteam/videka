VIDEKA — лендинг для Telegram-бота @videka7tro_bot

Файлы:
- index.html — готовая адаптивная страница на русском языке.

Как опубликовать:
1. Зарегистрируйся на статическом хостинге (например, GitHub Pages, Netlify или Cloudflare Pages).
2. Загрузи index.html как сайт / проект.
3. Получи публичный HTTPS-адрес.
4. Для собственного домена подключи домен в настройках хостинга.
5. Чтобы работать над появлением в Яндексе, добавь сайт в Яндекс Вебмастер и подтверди права на домен.
   Важно: добавление в Вебмастер не гарантирует показ в поиске; индексация может занять время.

Тексты на странице описывают только заявленный функционал и предупреждают, что скачивание зависит от доступности конкретного ролика и лимитов.
